Install Kampsis

You need macOS 26 or newer and a MacBook with Apple silicon and a lid angle sensor. This version is verified on Mac17,3; other models are experimental. The effect appears only on the built-in display. No internet connection is required to use the effect.

1. Copy the app

Drag the Kampsis icon onto the Applications folder in this window. Once it is copied you can close the window and eject the disk.

2. Open it the first time

  1. Launch Kampsis from the Applications folder.
  2. If macOS says it cannot verify the app, click Done.
  3. Open System Settings → Privacy & Security, find the line about Kampsis near the bottom and click Open Anyway.
  4. Confirm the launch. You will not be asked again.

This happens because the build is signed with the project’s own certificate rather than an Apple Developer certificate.

3. Allow screen access

  1. In the Kampsis window click Allow Screen Access….
  2. Turn Kampsis on in the Screen Recording section that opens.
  3. If macOS asks you to restart the app, agree.

The image is processed only in this Mac’s memory: nothing is saved and nothing is sent anywhere.

4. Try it

Lower the lid slowly or click Show on Screen. The ⌘ ⌥ B shortcut turns the effect on and off.

Left-click the menu bar icon to toggle the effect; right-click or Control-click it to open the menu. Closing the window does not quit Kampsis: choose Quit Kampsis in the menu to exit.

Updates

Check for Updates… in the menu compares your version with the latest GitHub release. Daily checks show an available version in General Settings and the menu without interrupting your work. A new version is installed by replacing the app in Applications. Your settings and screen recording permission are kept.

Установка Kampsis

Нужны macOS 26 или новее и MacBook с Apple silicon и датчиком угла крышки. Эта версия проверена на Mac17,3; работа на других моделях пока экспериментальная. Эффект появляется только на встроенном экране. Для работы эффекта интернет не нужен.

1. Скопируйте приложение

Перетащите иконку Kampsis на папку Applications в этом окне. После копирования можно закрыть окно и извлечь образ диска.

2. Запустите первый раз

  1. Откройте Kampsis из папки «Программы».
  2. Если macOS не может проверить приложение, нажмите Готово.
  3. Откройте Системные настройки → Конфиденциальность и безопасность, найдите сообщение о Kampsis внизу и нажмите Всё равно открыть.
  4. Подтвердите запуск.

Приложение подписано собственным сертификатом проекта, а не сертификатом Apple Developer.

3. Разрешите доступ к экрану

  1. В окне Kampsis нажмите Allow Screen Access….
  2. Включите Kampsis в открывшемся разделе «Запись экрана».
  3. Если macOS попросит перезапустить приложение, согласитесь.

Изображение обрабатывается только в памяти этого Mac: снимки не сохраняются и никуда не отправляются.

4. Попробуйте эффект

Медленно опустите крышку или нажмите Show on Screen. Сочетание ⌘ ⌥ B включает и выключает эффект.

Левый клик по иконке в строке меню переключает эффект. Правый клик или Control-click открывает меню. Закрытие окна не завершает работу: выберите Quit Kampsis, чтобы выйти.

Для русского интерфейса откройте General Settings → Language → Русский, затем перезапустите Kampsis.

Обновления

Проверить обновления… сравнивает установленную версию с релизом на GitHub. Автоматическая проверка показывает новую версию в Общих настройках и меню приложения. Для установки замените приложение в папке «Программы». Настройки и разрешение на запись экрана сохраняются.
